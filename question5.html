Question 5: Static Members, Algorithms, and Design Patterns

5 (a) - Static Class Members

Define a class `Car` with a static variable `totalCars` to count how many cars have been created. ... Include a constructor that updates `totalCars`... Implement a static function to display the total number of cars created, and another function to print individual car details. Use appropriate access specifiers. The `main()` function is given.

Key Concepts

  • Static Member Variable: A variable that belongs to the class itself, not to any specific object instance. All objects of the class share a single copy of the static variable. It must be defined and initialized outside the class.
  • Static Member Function: A function that belongs to the class and can be called without creating an object (`ClassName::functionName()`). It can only access other static members of the class.
  • Object Lifetime: Static members exist for the entire duration of the program's execution.

Diagram: Static vs. Instance Members in Memory


model: "Vitz" Object 2: car2 brand: "Honda"
model: "Vezel" Both objects share the single static variable

Complete Program Implementation

C++
#include <iostream>
#include <string>
using namespace std;
class Car {
private:
    string brand;
    string model;
    static int totalCars;
public:
    Car(const string& carBrand, const string& carModel) : brand(carBrand), model(carModel) {
        totalCars++;
        cout << "Constructor: A " << brand << " " << model << " was created." << endl;
    }
    void displayCarData() {
        cout << "Car Details: " << this->brand << " " << this->model << endl;
    }
    static void displayTotalCarNo() {
        cout << "Total number of cars created: " << totalCars << endl;
    }
};
int Car::totalCars = 0; // Initialization of static member
int main() {
    Car::displayTotalCarNo();
    Car car1("Toyota", "Vitz");
    Car car2("Honda", "Vezel");
    car1.displayCarData();
    car2.displayCarData();
    Car::displayTotalCarNo();
    return 0;
}

5 (b) - Scope and Output Analysis

Write down the output for the following program.

Key Concepts

  • Global Scope: A variable declared outside of all functions (`int i=5;`) is global. It can be accessed and modified from any function in the file.
  • Local Scope: A variable declared inside a function (`int a`) is local. It only exists within that function.
  • Pass-by-Value: When an argument is passed to a function, a *copy* of that argument is made. Changes to the parameter (`a`) inside the function do not affect the original variable (`i`) outside the function.

Code and Execution Trace

C++
int i=5; // Global variable
int say(int a) { // 'a' is a local copy of the argument passed.
    a = a * 5 % 7; // a becomes 25 % 7, so a is now 4.
    cout << a << endl; // Prints 4
    return ++a; // Pre-increments 'a' to 5, then returns 5.
}
void add() {
    ++i; // Increments the GLOBAL variable 'i'.
}
int main() {
    cout << say(i) << endl; // 1. say(5) is called. 2. It prints 4. 3. It returns 5. 4. main prints the returned 5.
    add(); // add() increments global 'i' from 5 to 6.
    cout << i << endl; // Prints the current value of global 'i', which is 6.
}

5 (c) - Flowchart Implementation

Write the C++ code segment to implement the algorithm shown by the following diagram.

Key Concepts

  • Flowchart: A visual representation of an algorithm's logic and flow.
  • Decision Symbol (Diamond): Represents an `if` or `while` condition.
  • Process Symbol (Rectangle): Represents an operation like an assignment or calculation.
  • Looping: The flowchart shows nested loops. The outer loop controls `i` and the inner loop controls `k`.

Interpreting the Flowchart

The flowchart is slightly ambiguous but can be interpreted as a nested loop structure. The outermost structure appears to be a loop controlling `i`. Inside it, a decision is made. If `i` is greater than 5 and less than 10, an inner loop for `k` is executed. Otherwise, `i` is just printed.

C++
#include <iostream>

int main() {
    // The outer loop is implied by the flow returning to the 'i' check.
    // Let's assume it iterates from 1 to 10 for demonstration.
    for (int i = 1; i <= 10; ++i) {
        // Decision diamond: "i < 10 && i > 5"
        if (i > 5 && i < 10) {
            // "True" path: Inner loop for 'k'
            // The flowchart shows k starting at 1 and looping while k < 10.
            for (int k = 1; k < 10; ++k) {
                std::cout << k << " "; // "print k"
            }
            std::cout << std::endl; // Newline after inner loop
        } else {
            // "False" path: Just print 'i'
            std::cout << i << std::endl; // "print i"
        }
    }
    return 0;
}

5 (e) - `const` Member Functions

Describe how the `const` keyword affects a C++ function using the given code segment as an example: `int getArea() const { ... }`

Key Concepts

  • `const` Correctness: A programming practice of using `const` to prevent unintended modifications to data, making code safer and easier to understand.
  • Constant Member Function: A member function that is not allowed to modify any of the non-static member variables of its class.
  • `const` Objects: An object declared as `const` cannot have its member variables changed after construction. Only `const` member functions can be called on a `const` object.

Explanation of `int getArea() const`

The `const` keyword at the end of the function declaration is a promise to the compiler and to other programmers. It makes two guarantees:

  1. The function will not modify the object's state. Inside `getArea()`, any attempt to change a member variable (e.g., `length = 10;`) would result in a compilation error. This function is "read-only".
  2. The function can be called on `const` objects. If you create a `const` object, you are only allowed to call its `const` member functions. This is crucial for working with constant data.

Code Example

C++
class Rectangle {
    int length, width;
public:
    Rectangle(int l, int w) : length(l), width(w) {}

    // Non-const function (can modify the object)
    void setLength(int l) { length = l; }

    // Const member function (promises not to modify)
    int getArea() const {
        // length = 10; // COMPILE ERROR! Cannot modify member in a const function.
        return length * width;
    }
};

int main() {
    const Rectangle constRect(10, 5);

    // OK: Calling a const function on a const object
    cout << "Area: " << constRect.getArea() << endl;

    // ERROR: Cannot call a non-const function on a const object
    // constRect.setLength(20); // COMPILE ERROR!
}

5 (f) - Observer Design Pattern

Briefly describe the usage of the Observer design pattern.

Key Concepts

  • Design Pattern: A reusable, general solution to a commonly occurring problem in software design.
  • Behavioral Pattern: A pattern that deals with communication between objects.
  • Loose Coupling: A design principle where components have minimal dependency on each other, making the system more flexible.

Core Idea of the Observer Pattern

The Observer pattern defines a one-to-many dependency between objects. When one object (the **Subject**) changes state, all of its dependents (the **Observers**) are notified and updated automatically. This is the foundation of event-driven programming.

Diagram: The Observer Pattern Interaction

Real-World Usage

  • Social Media: A person (Subject) posts an update. All their followers (Observers) get notified.
  • Model-View-Controller (MVC): The Model (data) is the Subject. The Views (UI elements) are Observers. When the data changes, all views that display it are automatically updated.
  • Event Listeners in GUIs: A button (Subject) notifies its listener objects (Observers) when a click event occurs.
