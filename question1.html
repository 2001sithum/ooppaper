1 (a) - Constructor & Double Increment in Loops

Write the output of the following program.

Key Concepts

  • Constructor: A special member function that is automatically executed when an object of a class is created. It's primarily used for initialization.
  • For Loop Execution Order: A `for` loop `for(init; cond; update)` executes in this order: 1. `init` (once), 2. `cond` (check), 3. Loop Body, 4. `update`, 5. Go to step 2.
  • Pre-increment (`++i`): Increments the variable's value *before* it is used in the current expression. It returns the *new* value.
  • Post-increment (`i++`): Uses the variable's *current* value in the expression and increments it *afterwards*. The loop's update step is a separate operation.

Code Analysis

C++
#include <iostream>
using namespace std;
class CuriousAdder{
public:
    CuriousAdder() {
        for(int i=0; i<=5; i++)
            cout<<++i;
    }
};
int main() { CuriousAdder ca; }

Line-by-Line Execution Trace

The core of this problem is the "double increment" of `i` within each loop cycle. One increment happens in the body (`++i`) and the other in the update expression (`i++`).

  1. Initialization: The loop starts. `int i` is initialized to `0`.
  2. Cycle 1:
    • Condition Check: `i <= 5` (0 <= 5) is true.
    • Loop Body: `cout << ++i;`. The pre-increment `++i` changes `i` from 0 to 1. This new value (1) is then printed.
    • Update Step: `i++` is executed. `i` is incremented from 1 to 2.
  3. Cycle 2:
    • Condition Check: `i <= 5` (2 <= 5) is true.
    • Loop Body: `cout << ++i;`. `++i` changes `i` from 2 to 3. This new value (3) is printed.
    • Update Step: `i++` is executed. `i` is incremented from 3 to 4.
  4. Cycle 3:
    • Condition Check: `i <= 5` (4 <= 5) is true.
    • Loop Body: `cout << ++i;`. `++i` changes `i` from 4 to 5. This new value (5) is printed.
    • Update Step: `i++` is executed. `i` is incremented from 5 to 6.
  5. Final Check:
    • Condition Check: `i <= 5` (6 <= 5) is now false. The loop terminates.

1 (b) - Conditional Loop Logic

Write the outputs for the following program when you enter "3" and "9" as inputs respectively.

Key Concepts

  • `if-else` Statement: Selects one of two blocks of code to execute based on a boolean condition.
  • `do-while` Loop: A loop that executes its body *at least once*, and then checks the condition to decide if it should continue.
  • `while` Loop: A loop that checks its condition *before* executing the body. The body may never execute if the condition is initially false.

Analysis for Input "3"

When the input is `3`, the member `i` of the `mp` object is initialized to 3. The `if (i < 5)` condition is true, so the `do-while` loop executes.

  1. The `do` block starts. `cout << i++` prints the current value of `i` (which is `3`) and then increments `i` to 4.
  2. The `while(i != 5)` condition is checked. `4 != 5` is true, so the loop repeats.
  3. The `do` block executes again. `cout << i++` prints the current value of `i` (which is `4`) and then increments `i` to 5.
  4. The `while(i != 5)` condition is checked. `5 != 5` is false, so the loop terminates.

1 (c) - Pointers & Dereference Operator

Explain the function of a dereference operator with an example.

Key Concepts

  • Pointer: A special variable that stores a memory address as its value. It "points to" the location of another variable.
  • Address-of Operator (`&`): A unary operator that returns the memory address of a variable. Used to initialize pointers.
  • Dereference Operator (`*`): A unary operator that, when applied to a pointer, accesses the value stored *at the memory address* the pointer holds. It is the inverse of the address-of operator.

Explanation

Imagine memory as a series of numbered mailboxes. A normal variable, like `int var = 100;`, means "put the value 100 in mailbox #502". A pointer, like `int* ptr = &var;`, means "the address #502 is written on a piece of paper inside another mailbox, let's call it `ptr`".

The dereference operator (`*`) is the action of "going to the address written on the paper (`ptr`) and opening that mailbox (`#502`) to see or change its content".

  • `ptr` gives you the address (`#502`).
  • `*ptr` gives you the value at that address (`100`).

Conceptual Diagram

Example Code with Annotations

C++
#include <iostream>
int main() {
    int number = 25;
    int* ptr_to_number; // Declare a pointer to an integer

    ptr_to_number = &number; // Use '&' to get the address of 'number' and store it in the pointer

    std::cout << "Value of 'number': " << number << std::endl;
    std::cout << "Address of 'number': " << &number << std::endl;
    std::cout << "Value of 'ptr_to_number' (it holds the address): " << ptr_to_number << std::endl;

    // Use '*' to dereference the pointer and get the value it points to
    std::cout << "Value pointed to by 'ptr_to_number': " << *ptr_to_number << std::endl;

    // We can also use the dereferenced pointer to modify the original variable's value
    *ptr_to_number = 100;
    std::cout << "New value of 'number' after modification via pointer: " << number << std::endl;

    return 0;
}

1 (d) - Object Instantiation and Method Calling

Write the main() function that would create an object of the `FindArea` class and call the `area()` function in it. Use 5 and 10 as integer values.

Key Concepts

  • Object Instantiation: The process of creating an instance (an object) of a class. Syntax: `ClassName objectName(arguments);`.
  • Member Initializer List: A more efficient way to initialize member variables in a constructor (e.g., `: a(a_val), b(b_val)`).
  • Member Access Operator (`.`): The dot operator is used to access public members (variables or functions) of an object.

Solution with Full Code

The solution requires two steps in `main()`: first, create an object of `FindArea` by passing the required values to its constructor, and second, use the dot operator to call the public `area()` method on that object.

C++
#include <iostream>
using namespace std;

class FindArea {
    int a, b;
public:
    // Constructor with member initializer list
    FindArea(int a_val, int b_val) : a(a_val), b(b_val) {}

    // Public method to perform the calculation
    void area() { cout << a * b; }
};

// The required main() function
int main() {
    // 1. Instantiate an object named 'calculator', passing 5 and 10
    FindArea calculator(5, 10);

    // 2. Call the 'area' method on the 'calculator' object
    calculator.area();

    return 0;
}

1 (e) - Recursion & Post-increment Nuances

Write down the output of the following program.

Key Concepts

  • Recursion: A programming technique where a function calls itself to solve a problem.
  • Base Case: A condition within a recursive function that stops the recursion (e.g., `if (i <= 10)`). Without a base case, recursion leads to a stack overflow.
  • Function Arguments: Arguments are evaluated *before* being passed to a function. The post-increment `i++` affects the local variable `i` *after* its value is used in the `cout` statement.

Code Analysis and Trace

This recursive function has a subtle behavior. `cout << i++` prints the current value of `i`, and *then* `i` is incremented. The recursive call `printNumbers(i + 1)` uses this newly incremented value plus one, causing the function to be called with arguments that skip numbers.

  • Call 1: `printNumbers(0)` is called. `0 <= 10` is true. `cout << i++` prints `0`. Local `i` becomes 1. The recursive call is `printNumbers(1 + 1)`, i.e., `printNumbers(2)`.
  • Call 2: `printNumbers(2)` is called. `2 <= 10` is true. Prints `2`. Local `i` becomes 3. Calls `printNumbers(3 + 1)`, i.e., `printNumbers(4)`.
  • Call 3: `printNumbers(4)` is called. `4 <= 10` is true. Prints `4`. Local `i` becomes 5. Calls `printNumbers(5 + 1)`, i.e., `printNumbers(6)`.
  • Call 4: `printNumbers(6)` is called. Prints `6`. Calls `printNumbers(8)`.
  • Call 5: `printNumbers(8)` is called. Prints `8`. Calls `printNumbers(10)`.
  • Call 6: `printNumbers(10)` is called. `10 <= 10` is true. Prints `10`. Local `i` becomes 11. Calls `printNumbers(11 + 1)`, i.e., `printNumbers(12)`.
  • Call 7: `printNumbers(12)` is called. `12 <= 10` is false. The function returns, and the recursion unwinds.

1 (f) - Enums & Loop Side-Effects

Create an `enum` with the days of the week. Write down the output when the given `main()` function calls the enum you created.

Key Concepts

  • `enum` (Enumeration): A user-defined data type that consists of a set of named integer constants called enumerators.
  • Default Enum Values: By default, the first enumerator has the value 0, the second has 1, and so on.
  • Side Effects: When an expression modifies a state (like changing a variable's value) in addition to producing a value. `i++` has the side effect of incrementing `i`.

Complete Code and Analysis

An `enum` provides meaningful names for integral constants. Here, `SUNDAY` will be `0`, `MONDAY` will be `1`, ..., and `SATURDAY` will be `6`. The `for` loop, like in question 1(a), has a double increment on the loop variable `day`.

C++
#include <iostream>
using namespace std;

// Your enum definition
enum Days { SUNDAY, MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY };

int main() {
    // SUNDAY is 0, SATURDAY is 6
    for (int day = SUNDAY; day <= SATURDAY; day++)
        cout << day++ << endl;
}

Execution Trace

  1. Cycle 1: `day` is 0. Condition `0 <= 6` is true. `cout << day++` prints `0`, then `day` becomes 1. The loop's update `day++` then makes `day` become 2.
  2. Cycle 2: `day` is 2. Condition `2 <= 6` is true. Prints `2`, `day` becomes 3. Loop update makes `day` 4.
  3. Cycle 3: `day` is 4. Condition `4 <= 6` is true. Prints `4`, `day` becomes 5. Loop update makes `day` 6.
  4. Cycle 4: `day` is 6. Condition `6 <= 6` is true. Prints `6`, `day` becomes 7. Loop update makes `day` 8.
  5. Final Check: `day` is 8. Condition `8 <= 6` is false. The loop terminates.
