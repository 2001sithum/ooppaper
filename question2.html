Question 2: Inheritance, Polymorphism & Data Structures

2 (a) - Implementing Inheritance from an Abstract Class

Following is an abstract class `Person`... Inherit from `Person` to create concrete derived classes `Student` and `Teacher`. The `Student` class should add a `grade` variable, and the `Teacher` class should add a `subject` variable. The overridden `getInfo()` function should print the attributes of each class.

Key Concepts

  • Abstract Class: A class that cannot be instantiated on its own. It acts as a blueprint for other classes. It must have at least one pure virtual function.
  • Pure Virtual Function: A virtual function with no implementation, declared by appending `= 0;`. It forces derived classes to provide their own implementation.
  • Concrete Class: A class that can be instantiated. A class derived from an abstract class becomes concrete once it implements all of the base class's pure virtual functions.
  • Inheritance: The mechanism of basing an object or class upon another object or class, retaining similar implementation. This promotes code reuse.
  • `override` Specifier: A C++11 keyword that indicates a member function in a derived class is intended to override a virtual function from a base class. It helps catch errors at compile time if the function signatures don't match.

Theoretical Foundation: Why Use Abstract Classes?

Abstract classes are central to polymorphism and creating flexible, extensible systems. They enforce a contract: any class that claims to be a "type of" `Person` *must* provide a way to get its information (`getInfo()`). This guarantees a common interface for a family of related classes, allowing you to treat `Student` and `Teacher` objects polymorphically through a `Person` pointer or reference, without needing to know their specific type at compile time.

Class Hierarchy Diagram (UML)

Complete Implementation Code

C++
#include <iostream>
#include <string>
using namespace std;

// Abstract Base Class 'Person'
class Person {
protected:
    // Protected members are accessible by this class and its derived classes
    string name;
    int age;
public:
    Person(const string& n, int a) : name(n), age(a) {
        cout << "LOG: Person constructor executed." << endl;
    }
    virtual void getInfo() const = 0;
    virtual ~Person() {
        cout << "LOG: Person destructor executed." << endl;
    }
};

// Concrete Derived Class 'Student'
class Student : public Person {
private:
    char grade;
public:
    Student(const string& n, int a, char g) : Person(n, a), grade(g) {
        cout << "LOG: Student constructor executed." << endl;
    }
    void getInfo() const override {
        cout << "--- Student Details ---\n";
        cout << "  Name:  " << name << "\n  Age:   " << age << "\n  Grade: " << grade << endl;
    }
    ~Student() { cout << "LOG: Student destructor executed." << endl; }
};

// Concrete Derived Class 'Teacher'
class Teacher : public Person {
private:
    string subject;
public:
    Teacher(const string& n, int a, const string& s) : Person(n, a), subject(s) {
        cout << "LOG: Teacher constructor executed." << endl;
    }
    void getInfo() const override {
        cout << "--- Teacher Details ---\n";
        cout << "  Name:    " << name << "\n  Age:     " << age << "\n  Subject: " << subject << endl;
    }
    ~Teacher() { cout << "LOG: Teacher destructor executed." << endl; }
};

2 (b) - Instantiating and Using Derived Classes

Write the `main()` function that creates objects of the `Student` and `Teacher` classes... and call the `getInfo()` function on each object.

Key Concepts

  • Object Instantiation: The process of creating an instance (an object) of a class in memory.
  • Constructor Chaining: When a derived class object is created, its constructor automatically calls the constructor of its base class first. This ensures the base part is properly initialized.
  • Destructor Chaining: When a derived object is destroyed, the destructor chain runs in the reverse order of the constructors: derived class destructor first, then the base class destructor.

Required `main()` Function

C++
// This main function would follow the class definitions from 2(a)
int main() {
    cout << "--- Creating Student Object ---" << endl;
    Student student1("Akalanka", 38, 'A');
    cout << endl;

    cout << "--- Creating Teacher Object ---" << endl;
    Teacher teacher1("Nishantha", 50, "OOP");
    cout << endl;

    cout << "--- Calling getInfo() Methods ---" << endl;
    student1.getInfo();
    cout << endl;
    teacher1.getInfo();
    cout << endl;

    cout << "--- main() is about to end, destructors will be called ---" << endl;
    return 0;
}

2 (c) - Using Structs

Write the `main()` function that would call the `struct book`, initialize its members, and print the values.

Key Concepts: `struct` vs. `class`

  • Default Access: The only real difference is default access. In a `struct`, members are `public` by default. In a `class`, members are `private` by default.
  • Convention/Usage: By convention, `struct`s are used for simple data aggregates (plain old data) with few or no methods. `class`es are used for complex objects with data and extensive methods, intended to model behavior and enforce invariants (rules) through encapsulation.

Complete Program with `main()`

C++
#include <iostream>
#include <string>
using namespace std;

struct book {
    // All these members are public by default
    int bookID;
    int numOfCopies;
    float price;
    string bookName;
};

int main() {
    // Create an instance of the struct
    book myBook;

    // Initialize members using the dot (.) operator
    myBook.bookID = 101;
    myBook.numOfCopies = 50;
    myBook.price = 29.99f;
    myBook.bookName = "The C++ Programming Language";

    // Print the values
    cout << "Book ID: " << myBook.bookID << endl;
    cout << "Book Name: " << myBook.bookName << endl;
    cout << "Price: $" << myBook.price << endl;
    cout << "Copies Available: " << myBook.numOfCopies << endl;

    return 0;
}

2 (d) - Output Analysis: Pointers, References, and Value Semantics

Write the output of the following program.

Key Concepts

  • Value Copy: `double number01 = number;` creates an independent copy. Changing `number` later will not affect `number01`.
  • Pointer (`*`): `double* number02 = &number;` stores the memory address of `number`. `*number02` accesses `number`'s value.
  • Reference (`&`): `double& number03 = *number02;` creates an alias for whatever `number02` is pointing to (which is `number`). From this point on, `number03` and `number` are two names for the same variable.
  • Pointer Reassignment: A pointer can be changed to point to a different variable's address.

Code and Execution Trace

C++
int main() {
    double number = 1000;
    double number01 = number;          // number01 is a copy, value is 1000
    double *number02 = &number;         // number02 points to 'number'
    double &number03 = *number02;       // number03 is a reference to 'number'

    cout << number << endl;             // Prints value of number: 1000
    *number02 = *number02 * 2;          // The value at the address of number is doubled. 'number' becomes 2000.
    cout << *number02 << endl;          // Prints the new value of number via pointer: 2000
    cout << number03 << endl;           // Prints the new value of number via reference: 2000

    number02 = &number01;               // Pointer now points to number01 (whose value is still 1000)
    cout << *number02 << endl;          // Prints the value of what number02 now points to: 1000
}

2 (e) - Loop Rewriting: `for` to `while`

Rewrite the following program only using `while` loops. Do not use `if`, `if-else`, `switch`, condition operator or `do-while` loops.

Key Concepts: Translating `for` to `while`

A `for` loop `for (initialization; condition; update)` can always be translated into an equivalent `while` loop structure:

initialization;
while (condition) {
    // loop body
    update;
}

Original `for` Loop Code

Original C++
for (int i = 5; i >= 0; i--) {
    for (int j = 1; j <= 5; j++) {
        cout << j;
    }
    cout << "\n";
}

Rewritten `while` Loop Code

Rewritten C++
#include <iostream>
using namespace std;

int main() {
    int i = 5; // Initialization for the outer loop
    while (i >= 0) { // Condition for the outer loop
        int j = 1; // Initialization for the inner loop
        while (j <= 5) { // Condition for the inner loop
            cout << j;
            j++; // Update for the inner loop
        }
        cout << "\n";
        i--; // Update for the outer loop
    }
    return 0;
}
