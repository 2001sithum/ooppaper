Concept: Inheritance (පරම්පරාගත බව)

Beginner Level: What is Inheritance?

English: Inheritance is one of the key features of Object-Oriented Programming. It allows a new class (called the **derived** or **child** class) to be based on an existing class (the **base** or **parent** class). The child class inherits the attributes and methods of the parent class, promoting code reusability. This creates an **"is-a"** relationship.

Sinhala (සිංහල): Inheritance කියන්නේ OOP වල ප්‍රධාන ලක්ෂණයක්. මේකෙන් අලුත් class (derived/child) එකකට, දැනට තියෙන class (base/parent) එකක ගුණාංග සහ ක්‍රියා උරුම කරගන්න (inherit) ඉඩ දෙනවා. Child class එකට parent ගේ දේවල් ලැබෙන නිසා, code එක නැවත නැවත ලිවීම (code reusability) අඩු වෙනවා. මේකෙන් හැදෙන්නේ **"is-a"** (එකක් වේ) සම්බන්ධතාවයක්.

Real-World Scenario

English: A `Manager` **is an** `Employee`. A `Developer` **is an** `Employee`. Both a `Manager` and a `Developer` will have a `name` and a `salary`, which can be defined in a parent `Employee` class. The `Manager` can then add a specific attribute like `teamSize`, and the `Developer` can add `programmingLanguage`. They both inherit the common properties from `Employee`.

Sinhala (සිංහල): `Manager` කෙනෙක් කියන්නේ `Employee` (සේවකයෙක්). `Developer` කෙනෙක් කියන්නෙත් `Employee` කෙනෙක්. `Manager` සහ `Developer` දෙන්නටම `name` එකක් සහ `salary` එකක් තියෙනවා. මේ පොදු දේවල් `Employee` කියන parent class එකේ හදන්න පුලුවන්. ඊට පස්සේ `Manager` class එකට `teamSize` වගේ එයාටම විශේෂ දෙයක් එකතු කරන්නත්, `Developer` class එකට `programmingLanguage` එකතු කරන්නත් පුලුවන්. දෙන්නම `Employee` ගෙන් පොදු දේවල් inherit කරගන්නවා.

Intermediate Level: Syntax and Access Specifiers

The syntax for inheritance in C++ is `class DerivedClass : accessSpecifier BaseClass`. The `accessSpecifier` (`public`, `protected`, or `private`) determines how the inherited members from the base class will be accessible in the derived class.

  • `public` Inheritance: This is the most common type. Public members of the base class stay public in the derived class. Protected members stay protected. This models a true "is-a" relationship.
  • `protected` Inheritance: Public and protected members of the base class become protected in the derived class.
  • `private` Inheritance: Public and protected members of the base class become private in the derived class. This models a "is-implemented-in-terms-of" relationship.

Sample Code 1: Single Inheritance

C++
#include <iostream>
#include <string>
using namespace std;

// Base / Parent Class
class Employee {
protected: // Protected so child classes can access it directly
    string name;
public:
    Employee(const string& n) : name(n) {}
    void work() { cout << name << " is working." << endl; }
};

// Derived / Child Class
class Manager : public Employee {
public:
    Manager(const string& n) : Employee(n) {} // Call base constructor
    void manage() { cout << name << " is managing a team." << endl; }
};

int main() {
    Manager mgr("Alice");
    mgr.work();   // Inherited from Employee
    mgr.manage(); // Its own method
    return 0;
}

Sample Code 2: Multilevel Inheritance

This example demonstrates a chain of inheritance (`GrandParent -> Parent -> Child`). The `Child` class inherits members from both `Parent` and `GrandParent`, showing how properties are passed down through generations.

C++
#include <iostream>
using namespace std;

// Level 1: The original base class
class GrandParent {
public:
    void grandParentLegacy() {
        cout << "This is a legacy from the GrandParent." << endl;
    }
};

// Level 2: Inherits from GrandParent
class Parent : public GrandParent {
public:
    void parentAsset() {
        cout << "This is an asset from the Parent." << endl;
    }
};

// Level 3: Inherits from Parent (and indirectly from GrandParent)
class Child : public Parent {
public:
    void childSkill() {
        cout << "This is a skill of the Child." << endl;
    }
};

int main() {
    Child myChild;

    cout << "Child's capabilities:" << endl;
    myChild.childSkill();         // Accesses its own method
    myChild.parentAsset();        // Accesses Parent's method
    myChild.grandParentLegacy();  // Accesses GrandParent's method

    return 0;
}

Advanced Level: Types of Inheritance and Problems

  • Single Inheritance: A class inherits from only one base class. (Sample Code 1).
  • Multilevel Inheritance: A class inherits from a derived class, forming a chain (`A -> B -> C`). (Sample Code 2).
  • Multiple Inheritance: A class inherits from two or more base classes (`class C : public A, public B`). This can lead to ambiguity if both base classes have a member with the same name.
  • Hierarchical Inheritance: Multiple classes inherit from a single base class (e.g., `Manager` and `Developer` both inheriting from `Employee`).
  • Hybrid Inheritance: A combination of two or more of the above types.

The Diamond Problem

A classic issue in multiple inheritance. It occurs when a class `D` inherits from two classes, `B` and `C`, and both `B` and `C` inherit from a single base class `A`. This means `D` gets two copies of `A`'s members, causing ambiguity.

Solution: C++ solves this using **virtual inheritance**. By making the inheritance from `A` to `B` and `C` virtual (`class B : virtual public A`), it ensures that `D` receives only a single shared copy of `A`'s members.
